# kadai03_memo
- 工程管理検査記録

## ②課題内容（どんな作品か）
- 建設現場における諸検査等の進捗を管理するツールです。
「対象フロア」「対象工区」「検査項目」「検査予定日」「検査実施日」を入力するだけで、予定と実績のズレ（遅延・前倒し日数）を自動計算し、記録します。

## ③アプリのデプロイURL

## ④アプリのログイン用IDまたはPassword（ある場合）
- なし

## ⑤工夫した点・こだわった点
- 自動計算で「遅れ」が発生したデータだけ、文字を自動で赤色・太字に変更して一目でトラブルが分かるようにしました。
- Flexboxを使って「フロア」と「工区」の選択欄をすっきり横並びに配置しました。
- Google Apps Script（GAS）経由でGoogleスプレッドシートへリアルタイムに自動保存される仕組みを構築しました。


## ⑥難しかった点・次回トライしたいこと（又は機能）
- GASのデプロイや権限設定などが難しかった。
- 間違えて登録したデータを1件ずつ消去・修正できるボタンの実装。
- 他社写真管理ツール（SpiderPlus等）とのAPI連携 

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- 簡易版でも自分が建設現場にあれば良いなと思えるものが形にできたので嬉しい。これを現場のオペレーションを変えずに導入できる、現実的なSaaSとして実装したいです。
